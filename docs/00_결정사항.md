# 00. 결정사항

최종 갱신: 2026-10-07

## 챌린지 개요 (공지 기준)

| 항목 | 내용 |
|---|---|
| 이름 | 당찬동행 챌린지 (xikers와 함께) |
| 주최 / 후원 | (사)한국1형당뇨병환우회 · 한국췌장장애인협회 / sanofi |
| 기간 | **2026-10-06(화) ~ 11-14(토)** |
| 음악 | "Rhythm check" 노래를 틀고 자유롭게 촬영 |
| 참여 방식 | 정식 안무, 쉬운 손동작 안무, 걷기, 응원 문구 들기, 뒷모습, 가족·친구·반려동물과 함께 |
| 업로드 | 필수 해시태그 `#당찬동행` `#나를지키는인슐린`, TikTok·Instagram·Facebook·YouTube |
| 대리 업로드 | 직접 올리기 어려우면 환우회 계정으로 참여 가능 (댓글로 신청) |
| 분위기 | "박자를 조금 놓쳐도, 정식 안무가 아니어도 괜찮아요" |

## 확정된 결정

| # | 결정 | 비고 |
|---|---|---|
| D1 | **목적**: 챌린지 참여 창구를 하나 더 추가. AI로 만든다는 점이 참여를 늘리는 흥미 요소가 되길 기대 | 운영자는 "영상 제작 창구"만 제공 |
| D2 | **업로드는 참여자 개인이 직접** 한다 | 챌린지 취지에 맞추기 위함 |
| D3 | **규모·예산**: 참여 100명 이하 예상, 예산 0원, 개인 프로젝트 | 유료 도구(Higgsfield 등) 사용하지 않음 |
| D4 | **제작 환경**: ComfyUI 클라우드(Comfy Cloud). 참여자 PC에서 직접 돌리지 않음 | OS·사양 영향 없음, 모두 같은 환경 |
| D5 | **레퍼런스 영상은 2개만** 사용: A 쉬운 손동작(15.1초), B 정식 안무(37.8초) | 나머지 영상은 개인이 촬영한 것이라 제외 |
| D6 | **음원**: 기본값은 레퍼런스 영상의 음원을 그대로 넣는다. 인스타에서 음악을 직접 고르거나, 원곡을 받아 합성해도 됨 | 챌린지용으로 공유된 음원이라 저작권 이슈가 없다는 것이 운영자 판단 |
| D7 | **AI 표시 문구는 영상에 넣지 않는다.** 대신 SNS에 올릴 때 플랫폼의 AI 라벨을 켜도록 안내 | 앱 화면 확인 후 가이드에 반영 (T8) |
| D8 | 해시태그 안내는 가이드에 넣는다 (`#당찬동행` `#나를지키는인슐린`) | |
| D9 | 협회 협업, 대리 업로드, 참여자 동의 수집은 **하지 않는다** | 앱 이용 범위에서는 해당 없음 |
| D10 | 단, 환경 문제로 직접 못 만드는 사람은 **운영자가 받아서 대신 제작**한다. 이때만 개인정보 동의서를 받는다 (네이버폼) | 문안 초안: [06](06_네이버폼_문안_초안.md) |
| D11 | 결과물을 만들어 본 뒤 협회 허가를 받는다 | 반대하지 않을 것으로 예상 |
| D12 | **저장소 용도**: 가이드, 결과물 정리, 공유. 조사와 시험은 로컬 세션이 하고 결과를 `results/`에 올린다 | 클라우드 세션은 외부 사이트 접근이 막혀 조사에 제약이 큼 |

## 미확정 (제안 상태)

| # | 항목 | 제안 | 결정 시점 |
|---|---|---|---|
| P1 | 지원 범위 | 정면 상반신 사진 + A/B 두 영상. 가족·반려견·뒷모습은 1차 제외 | 시험 후 |
| P2 | 사용 모델 | SCAIL-2와 Wan2.2 Animate를 같은 조건에서 비교해 선택 | T12 |
| P3 | 대리 제작 접수 상한 | 1인 1건, 선착순 ⟦N⟧명 등. 소요 시간 실측 후 결정 | T1, T14 |
| P4 | 가이드 공개 채널 | GitHub Pages 또는 별도 공유 페이지 | 시험 후 |
| P5 | 로고·자막 없는 원본 영상 보유 여부 | 있으면 교체, 없으면 번짐 정도를 시험으로 판단 | T2 |
| P6 | 표시 문구 제거에 따른 법적 위험 | 인공지능기본법 표시 의무는 '사업자'에게 있고, 개인 무상 배포가 이에 해당하는지는 불확실. 협회 허가 때 함께 문의 | 허가 단계 |
