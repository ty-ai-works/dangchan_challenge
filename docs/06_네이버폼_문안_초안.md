# 06. 네이버폼 문안 초안 (대리 제작 신청)

> **법률 검토를 거친 문안이 아닌 초안입니다.** 공개 전에 직접 읽고 수정하세요. `⟦ ⟧`는 채울 값입니다.
> 이 폼은 **환경 문제로 직접 만들 수 없는 분**만 쓰는 용도입니다 (앱을 직접 쓰는 경우는 해당 없음, 결정 D9·D10).

## 폼 구성

### 1. 안내 문구 (폼 첫 화면)

> 직접 영상을 만들기 어려운 분을 위한 **대리 제작 신청**입니다.
> 보내 주신 사진으로 AI 댄스 영상을 만들어 전달해 드립니다. 영상 업로드는 신청하신 분이 직접 하셔야 합니다.
> 개인이 운영하며 협회 공식 서비스가 아닙니다. 접수 상한(선착순 ⟦N⟧명)과 제작 시간(⟦X⟧일 이내 목표) 때문에 요청이 늦어지거나 어려울 수 있습니다.

### 2. 신청 정보

| 문항 | 유형 | 필수 | 비고 |
|---|---|---|---|
| 호칭(닉네임 가능) | 단답 | 필수 | |
| 결과를 받을 연락 방법 | 선택(이메일/카카오톡/기타) + 단답 | 필수 | 최소한의 연락처만 받음 |
| 따라 할 영상 | 선택: A 쉬운 손동작(15초) / B 정식 안무(38초) | 필수 | |
| 사진 첨부 | 파일 | 필수 | 정면 상반신 1장. 첨부 한도 ⟦T10⟧ |

| 요청 사항 | 장문 | 선택 | |

### 3. 개인정보 수집·이용 동의

| 항목 | 내용 |
|---|---|
| 수집 항목 | 얼굴이 나온 사진, 호칭, 연락 방법, 요청 사항 |
| 수집·이용 목적 | AI 댄스 영상 제작과 결과물 전달 |
| 처리 방식 | 사진은 영상 제작을 위해 ⟦운영자 개인 PC / Comfy Cloud 등 외부 클라우드 서비스⟧에서 처리되며, 외부 서비스에 업로드될 수 있습니다 ⟦실제 처리 방식 확정 후 하나만 남기기⟧ |
| 보유·이용 기간 | 결과물 전달 후 **⟦7⟧일 이내 사진과 결과 영상을 삭제**합니다 (제안값) |
| 제3자 제공 | 하지 않습니다 (위 처리 방식에 적은 서비스 이용은 제외) |
| 동의 거부 권리 | 동의하지 않으셔도 됩니다. 이 경우 대리 제작은 어렵지만, 앱을 직접 이용하는 방법은 그대로 쓸 수 있습니다 |
| 철회·삭제 요청 | ⟦연락처⟧로 언제든 요청할 수 있습니다 |

**동의 체크 문항 (필수)**

- [ ] 위 내용에 동의합니다
- [ ] 이 영상이 **AI로 만든 영상**임을 알고 있으며, SNS에 올릴 때 AI 라벨을 켜겠습니다
- [ ] 사진 속 인물은 본인이거나 사용을 허락받은 사람입니다

### 4. 만 14세 미만 아동 (해당 시에만 표시)

만 14세 미만 아동의 개인정보를 처리하려면 **법정대리인의 동의**가 필요합니다 (개인정보 보호법). 아동이 사진 속 인물이면 아래를 받으세요.

- [ ] 저는 사진 속 아동의 법정대리인(보호자)이며, 위 개인정보 수집·이용에 동의합니다
- 법정대리인 호칭, 아동과의 관계 (단답)

### 5. 폼 설정 확인 사항 (게시 전)

- [ ] 응답 열람 권한이 운영자 본인에게만 있는지
- [ ] 응답 데이터(사진 포함)를 **저장소에 올리지 않는 것**을 다시 확인 (`.gitignore`로도 막아 두었지만 직접 주의)
- [ ] 보유 기간이 지나면 응답에서 사진을 삭제하는 날짜를 달력에 표시
- [ ] 접수 마감과 상한 도달 시 폼 닫기
