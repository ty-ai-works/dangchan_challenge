# 01. 타당성 검토

검토일: 2026-10-07

## 결론

**기술적으로는 실현 가능합니다.** 다만 아래 세 가지는 실측 전에는 확정할 수 없습니다.

1. 손동작·표정·로고 번짐 등 **품질**이 쓸 만한가
2. 무료 크레딧 한도 안에서 **참여자 1인당 몇 편**까지 만들 수 있는가
3. **무료 계정이 공유된 앱을 실행**할 수 있는가

## 기술

- **방식**: 모션 트랜스퍼. 사진 속 인물이 레퍼런스 영상의 동작을 따라 하는 영상을 만듭니다. 외형(의상·헤어)은 사진을 따르고 동작만 영상에서 가져옵니다.
- **기존 메모의 "AnimateAnyone 계열"**은 공식 코드가 공개되지 않았고 비공식 재구현(SD1.5 기반)이 중심이라 품질이 낮은 편입니다. 현재 후보는 다음과 같습니다.
  - Wan2.2 Animate (Apache 2.0)
  - SCAIL-2 ([ComfyUI 코어에 기본 내장](https://comfyui-wiki.com/en/news/2026-06-09-scail-2-character-animation), 별도 노드 설치 불필요)
- **한국이 라이선스 적용 지역에서 제외된 모델**(MiniMax-H3, HunyuanVideo 1.5 등)은 쓰지 않습니다. 이전 세션의 조사 결과이며, 본 프로젝트에서 별도로 재검증하지는 않았습니다.

### 조건별 평가

| 조건 | 판단 | 비고 |
|---|---|---|
| 사진 외형 유지, 동작만 복제 | 가능 | 모션 트랜스퍼의 핵심 기능 |
| 남녀 구분 | 별도 처리 불필요 | 외형이 사진에서 그대로 오므로 성별 판별 로직이 필요 없음 |
| 의상·헤어 반영 | 가능(시험 필요) | 레퍼런스의 의상이 섞이지 않는지 T2·T13에서 확인 |
| 손동작 | **가장 위험** | A영상은 손가락 동작이 핵심 |
| "완벽한 고화질·자연스러움" | 보장 불가 | 얼굴 변형, 손 깨짐이 간헐적으로 생길 수 있음. 재시도 안내 필요 |
| 긴 영상(B 37.8초) | 불확실 | 무료 10분 제한에 걸릴 수 있어 분할이 필요할 수 있음 |
| 가족·반려견 동반 | 1차 제외 | 다인 합성은 난도가 크게 올라감 |
| 음원 | 가능 | 영상의 오디오 트랙을 결과에 합성 (T6) |

## 구현 경로 비교 (과거 논의 요약)

| 경로 | 비용 | 문제 | 결과 |
|---|---|---|---|
| 상용 API (Kling Motion Control 등) | 건당 약 $1~2.5 (검색 기준, 15초 가정) | 예산 0원 조건과 충돌 | 제외 |
| 참여자 로컬 PC 실행 | 0원 | 14B급 모델은 높은 사양 필요, OS별 설치 지원 부담, 대부분의 참여자는 실행 불가 | 제외 |
| 운영자 PC에서 대신 제작 | 0원 | 사용자 PC(RTX 3060 12GB)에서 5초 클립 1건이 약 45분, 100명이면 수백 시간 | 폴백으로만 사용 |
| **Comfy Cloud (앱 모드 공유)** | 참여자 무료 크레딧 | 무료 한도, 계정 가입 필요, 약관·정책 변동 | **채택** |

## 비용 (0원 조건 점검)

운영자는 비용이 들지 않습니다. 참여자는 본인 Comfy Cloud 계정의 무료 크레딧을 씁니다. 한도 계산은 [03](03_ComfyCloud_방식.md)을 참고하세요.
