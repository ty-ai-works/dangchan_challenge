# 03. Comfy Cloud 방식

조사일: 2026-10-07 (클라우드 세션의 웹 검색 요약 기준. 공식 페이지 다수는 접근 차단되어 **원문 확인 전**이며, 로컬에서 재확인 필요)

## 구조

```
[참여자]
  └─ Comfy Cloud 무료 계정 가입
      └─ 공유된 앱 링크 열기 (App Mode, 설치 없음)
          ├─ 입력 1: 내 사진 업로드
          ├─ 입력 2: 따라 할 영상 선택 (A 쉬운 손동작 / B 정식 안무)
          └─ 실행 (참여자 본인 크레딧 소모)
              └─ mp4 다운로드 (영상 음원 포함)
                  └─ 인스타 등에 직접 업로드 (해시태그, AI 라벨)

[운영자]  워크플로 제작 → App Builder로 앱화 → 링크 공유 → 가이드 배포
          (환경 문제로 못 만드는 참여자 → 네이버폼 접수 → 대신 제작)
```

## 확인된 사실과 신뢰도

| 항목 | 내용 | 출처 | 신뢰도 |
|---|---|---|---|
| App Mode | 워크플로를 입력·출력만 보이는 화면으로 변환. 링크를 가진 사람은 그래프를 보지 않고 설치 없이 실행 가능(Comfy Cloud 기준) | [Comfy 블로그](https://blog.comfy.org/p/from-workflow-to-app-introducing) | 중 (검색 요약) |
| 프론트엔드 버전 | App Mode는 1.41.13 이상에서 공식 지원 | [문서](https://docs.comfy.org/interface/app-mode) | 중 |
| 무료 티어 | 월 400크레딧, 매달 갱신, 카드 불필요 | [Comfy 블로그](https://blog.comfy.org/p/free-tier-arrives-in-comfy-cloud) | 중. **초기에는 "무료 5회 실행"이었다는 요약도 있어 정책 개편 이력 있음** |
| 무료 최대 실행 시간 | 워크플로당 10분 | 위와 동일 | 중 |
| 유료 요금 | Standard $20/월 4,200크레딧(최대 30분), Creator $35 7,400, Pro $100 21,100(최대 1시간) | [요금](https://comfy.org/pricing/) | 중 |
| 크레딧 소모 | GPU 시간 기준 약 0.39크레딧/초 (약 23크레딧/분) | 요금 페이지 요약 | 중 |
| 동시 실행(API) | Standard 1, Creator 3, Pro 5. 무료는 명시 없음 | 검색 요약 | 낮음 |
| GPU | RTX Pro 6000 Blackwell, VRAM 96GB | 검색 요약 | 중 |
| 사전 설치 노드 | WanVideoWrapper(51개 노드), KJNodes(41개), VideoHelperSuite 등 [지원 노드 목록](https://comfy.org/cloud/supported-nodes/ComfyUI-WanVideoWrapper.md) | 공식 목록 | 중~높음 |
| 임의 노드 설치 | 불가(큐레이션 목록만) | 검색 요약 | 중 |
| SCAIL-2 | ComfyUI 코어에 내장, 가중치 등록됨 | [ComfyUI Wiki](https://comfyui-wiki.com/en/news/2026-06-09-scail-2-character-animation) | 중 |
| 워크플로 공유 링크 | 받는 사람이 **입력·출력·참조 자산까지** 볼 수 있음 | [공유 문서](https://docs.comfy.org/cloud/share-workflow) | 중 |
| 약관 | 베타 서비스, 가용성·데이터 보존에 대한 보증 없음, 종료 후 최대 30일 보관 | [ToS](https://www.comfy.org/terms-of-service) | 중 |

## 크레딧 계산

| | 계산 | 결과 |
|---|---|---|
| 무료 400크레딧 | 400 ÷ 0.39 | 약 1,026초 = **GPU 약 17분/월** |
| Standard 4,200크레딧 | 4,200 ÷ 0.39 | 약 10,769초 = GPU 약 3시간/월 |

### 영상 1편 비용 시나리오 (⚠ 가정, 실측으로 교체 필요)

A영상(15초)을 만드는 데 걸리는 GPU 시간을 가정했을 때:

| GPU 시간 가정 | 크레딧 | 무료 한도로 만들 수 있는 편수/월 |
|---|---|---|
| 3분 | 약 70 | 5편 |
| 6분 | 약 140 | 2편 |
| 10분 | 약 234 | 1편 (10분 제한에 아슬아슬) |

참고로 공식 안내는 무료 400크레딧으로 Wan 2.2 이미지-투-비디오 5초 영상 약 35편이라고 합니다. 하지만 이는 가벼운 템플릿 기준이며, Animate 계열은 영상이 3배 길고 모델이 무거워 **훨씬 적게 나올 가능성이 큽니다.** 챌린지 기간(10/6~11/14)에 월 갱신이 한 번 걸칠 수 있습니다.
