# 사진 한 장으로 따라 추는 당찬동행 챌린지 (AI 영상 만들기)

> 초안입니다. `⟦ ⟧`로 표시한 부분은 시험 결과가 나오면 채웁니다. 시험 전에는 공개하지 마세요.

## 이게 뭐예요?

당찬동행 챌린지는 **정식 안무, 쉬운 손동작, 걷기, 뒷모습, 응원 문구 들기** 등 어떤 방식으로 참여해도 괜찮습니다. 직접 촬영이 부담스러운 분을 위해 **참여 방법을 하나 더** 준비했습니다.

내 사진을 올리면 AI가 챌린지 안무를 따라 하는 영상을 만들어 줍니다. **영상을 올리는 일은 직접** 해 주세요. 챌린지 기간은 10월 6일 ~ 11월 14일입니다.

## 먼저 알아두세요

- 이 영상은 **AI로 만든 영상**입니다. 올릴 때 AI 라벨을 켜 주세요 ([아래](#올리기))
- 내 사진은 외부 서비스(Comfy Cloud)에 올라가 처리됩니다. 서비스 약관상 종료 후 최대 30일 보관될 수 있습니다 ⟦T5 확인 후 수정⟧
- **본인 사진이나 사용을 허락받은 사진만** 쓰세요
- 결과가 어색하거나 손가락이 깨질 수 있습니다. 여러 번 시도하거나 사진을 바꿔 보세요
- 챌린지 공식 서비스가 아니라 개인이 만든 도우미입니다

## 준비물

| 준비물 | 설명 |
|---|---|
| 사진 1장 | 아래 "사진 고르기" 참고 |
| Comfy Cloud 계정 | 무료. 가입 방식 ⟦T4 확인⟧ |
| 크레딧 | 무료 계정은 매달 400크레딧. 영상 1편에 약 ⟦N⟧크레딧이 들어서 한 달에 약 ⟦M⟧편 가능 ⟦T1 실측 후 기입⟧ |
| 기기 | PC 브라우저 권장. 휴대폰 사용 가능 여부 ⟦T7⟧ |

## 사진 고르기

**정면을 보고, 허리 위부터 허벅지까지 나온 사진**이 가장 잘 나옵니다 ⟦T13 확인 후 수정⟧.

- 얼굴이 크게 나오고 이목구비가 뚜렷한 사진
- 조명이 밝은 사진
- 팔과 어깨가 가려지지 않은 사진
- 한 명만 나온 사진
- 피해야 할 사진: 어두운 사진, 얼굴이 작은 사진, 옆모습, 모자·마스크로 얼굴이 가려진 사진, 여러 명이 나온 사진

## 만들기

1. 안내받은 **앱 링크**를 엽니다 ⟦링크⟧
2. Comfy Cloud에 로그인합니다 (처음이면 가입) ⟦T4⟧
3. **내 사진**을 올립니다
4. 따라 할 영상을 고릅니다
   - **A. 쉬운 손동작 안무** (15초) — 처음이라면 추천
   - **B. 정식 안무** (38초) ⟦T11 결과에 따라 안내⟧
5. **실행**을 누르고 기다립니다. 보통 ⟦X⟧분 걸립니다
6. 완성되면 영상을 **다운로드**합니다

## 음악

기본적으로 **챌린지 음원이 영상에 들어 있습니다.** 올릴 때 인스타그램 등에서 음악을 직접 고르고 싶다면 영상 소리를 끄고 앱의 음악 기능을 쓰면 됩니다 ⟦T6, T8 확인 후 설명 보강⟧.

## 올리기

1. 인스타그램, 틱톡, 유튜브, 페이스북 중 편한 곳에 올립니다
2. 필수 해시태그 두 개를 넣어 주세요
   - `#당찬동행`
   - `#나를지키는인슐린`
3. **AI 라벨을 켜 주세요.** ⟦T8의 한국어 메뉴 경로와 화면 캡처를 여기에 넣기⟧

## 안 될 때

| 증상 | 해결 |
|---|---|
| 크레딧이 모자라요 | 다음 달 1일 갱신을 기다리거나, 아래 "대신 만들어 드려요"를 이용하세요 ⟦갱신일 T1에서 확인⟧ |
| 실행이 중간에 멈추거나 오류가 나요 | 사진을 다른 것으로 바꿔 다시 실행해 보세요 |
| 얼굴이 이상하게 나와요 | 얼굴이 크고 정면인 사진으로 바꿔 보세요 |
| 손가락이 깨져요 | 영상 A·B를 바꿔 보거나 다시 실행해 보세요 |
| 가입이 안 돼요 | 아래 "대신 만들어 드려요"를 이용하세요 |
