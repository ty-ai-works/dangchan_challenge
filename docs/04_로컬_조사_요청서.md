# 04. 로컬 조사 요청서

이 문서는 **로컬 Claude Code 세션**(과 사용자)이 이어서 할 조사·시험 목록입니다. 이 문서만 읽어도 작업할 수 있도록 맥락을 포함했습니다.

## 맥락 (5줄 요약)

- 당찬동행 챌린지(2026-10-06 ~ 11-14) 참여자가 **사진 한 장으로 챌린지 안무를 따라 하는 AI 영상**을 만드는 창구를 추가하는 개인 프로젝트입니다. 업로드는 참여자가 직접 합니다.
- 제작 환경은 **Comfy Cloud**입니다 (참여자 PC 사양·OS와 무관). 워크플로를 App Mode로 앱화해 링크로 공유하는 구조입니다.
- 레퍼런스 영상은 **A(쉬운 손동작 15.1초)와 B(정식 안무 37.8초)** 두 개뿐입니다. 규격과 주의점은 [02](02_레퍼런스_영상_분석.md)에 있습니다.
- 예산 0원, 예상 참여 100명 이하. **유료 구독 결제나 유료 도구(Higgsfield 등) 사용은 사용자 확인 없이 하지 않습니다.**
- 클라우드 세션은 외부 사이트 접근이 막혀 있어 공식 문서와 약관을 직접 읽지 못했습니다. 그 부분이 이 요청서의 핵심입니다. 배경: [00](00_결정사항.md), [01](01_타당성_검토.md), [03](03_ComfyCloud_방식.md)

## 작업 원칙

1. 시험용 사진은 **본인 사진이나 AI로 만든 가상 인물**만 씁니다. 제3자 사진 금지.
2. 참여자 사진, 개인정보, 계정 정보, 토큰은 저장소에 **올리지 않습니다.**
3. 수치는 **직접 측정한 값**과 **문서에서 읽은 값**을 구분해서 적습니다. 문서에서 읽었다면 URL과 조회일을 남깁니다.
4. 🧑는 브라우저 조작이 필요한 항목(사용자가 직접), 🤖는 로컬 Claude 세션이 처리할 수 있는 항목입니다.
5. 로컬 세션의 토큰이 부족하면 P0만 먼저 끝내고 P1·P2는 건너뛰어도 됩니다. 기록 형식은 [results/_templates](../results/_templates/)를 쓰세요.

## 조사 항목

### P0 — 가이드를 확정하기 전에 반드시 필요

| # | 작업 | 방법 | 기록할 것 | 담당 |
|---|---|---|---|---|
| **T1** | 공식 템플릿 실행·실측 | Comfy Cloud **무료 계정**에서 템플릿 라이브러리를 열어 SCAIL-2와 Wan2.2 Animate 관련 템플릿이 있는지 확인. 영상 A로 실행 | 템플릿 이름, 해상도, 프레임수, 출력 fps, **GPU 시간, 실행 전후 크레딧**, 실패·오류 메시지 | 🧑 |
| **T2** | 품질 평가 | T1 결과를 아래 체크리스트로 평가 | 손가락, 팔 교차(B), 얼굴 유지, 표정 전이, 로고·자막 번짐, 의상·헤어 유지, 배경 | 🧑🤖 |
| **T3** | 앱화 | 워크플로를 App Mode로 구성. 입력은 **사진 업로드 + 영상 선택(A/B)**, 출력은 영상. 공유 링크 발급 | 앱에서 쓸 수 있는 입력 위젯 종류, 불가능했던 것 | 🧑 |
| **T4** | **무료 계정으로 공유 앱 실행** | T3 링크를 **다른 무료 계정**(새 계정이나 지인)으로 열어 실행 | 가입 방식, 카드·휴대폰 인증 요구 여부, 로그인 필요 여부, **크레딧이 실행자 것인지**, 설치 필요 여부 | 🧑 |
| **T5** | 약관 원문 확인 | Comfy Cloud 이용약관·허용 사용 정책을 읽고 **실존 인물 사진, 합성 미디어(딥페이크), 미성년자, 공유 앱 배포** 관련 조항을 원문 발췌 | 조항 인용, URL, 조회일, 본 프로젝트에 미치는 영향 한 줄 | 🤖 |
| **T6** | 음원 합성 | 결과 영상에 **레퍼런스 영상의 오디오**를 입히는 방법 확인. 워크플로 안에서 처리(VideoHelperSuite 등) 또는 후처리(ffmpeg) | 싱크·길이 일치 여부, A의 피크 0.0dB 클리핑 문제, 음량 정규화(loudnorm 등) 필요성, 사용한 명령/노드 | 🧑🤖 |

**T2 체크리스트** (결과마다 O/△/X 와 한 줄 메모)

- [ ] 손가락 모양이 레퍼런스와 비슷하고 깨지지 않는다
- [ ] 팔이 교차·겹치는 구간에서 팔이 뒤틀리지 않는다 (B)
- [ ] 얼굴이 사진 속 사람으로 유지된다
- [ ] 표정이 어색하지 않다 (레퍼런스의 노래하는 입 모양이 따라오는지)
- [ ] 로고·"Rhythm check"·자막이 결과에 번지지 않는다
- [ ] 의상·헤어가 사진을 따른다 (레퍼런스 의상이 섞이지 않는다)
- [ ] 배경이 어색하지 않다
- [ ] 박자와 음원이 어긋나지 않는다
