# 02. 레퍼런스 영상 분석

분석일: 2026-10-07 · 방법: ffprobe, ffmpeg 장면 전환 감지, 프레임 목시 확인

## 규격

| | A. 쉬운 손동작 안무 | B. 정식 안무 |
|---|---|---|
| 길이 | 15.15초 | 37.81초 |
| 해상도 | 720×1276 세로 | 720×1276 세로 |
| 프레임레이트 | 30fps | 30fps |
| 비디오 / 오디오 | H.264 / AAC 44.1kHz 스테레오 | 동일 |
| 파일 크기 | 약 2.2MB | 약 5.2MB |
| 총 프레임(30fps) | 약 454 | 약 1,134 |
| 16fps 환산 프레임 | 약 242 | 약 605 |
| 컷 전환 | 없음 (장면 변화 0.3 초과 0회) | 없음 |
| 음량 | 평균 -11.1dB, **피크 0.0dB** | 평균 -17.5dB, 피크 -3.5dB |

- 1276은 16의 배수가 아니라서 모델 입력 시 720×1280 등으로 맞춰야 합니다. 차이는 0.3% 안팎입니다.
- 16fps 환산은 Wan 계열 기본 출력이 16fps 안팎인 경우가 많다는 가정입니다. 실제 값은 템플릿마다 다르므로 T1에서 확인합니다.

## 화면 구성

| | A | B |
|---|---|---|
| 인물 | 단일 인물, 검은 긴 머리, 회색 반팔 | 단일 인물, 단발, 흰 오프숄더 상의 + 회색 와이드 팬츠 |
| 구도 | 허벅지 위까지 보이는 정면 상반신, 고정 카메라 | 동일 |
| 배경 | 보라색 그라데이션 조명 | 연습실 (시계, 선반, 조명 장식 등 사물이 많음) |
| 동작 | **손가락 동작이 핵심**: 펼친 손, 손 모양 만들기, 가리키기 | 팔 동작이 크고, **팔이 몸·얼굴 앞에서 교차하거나 겹치는 구간**이 있음 |
| 표정 | 노래하듯 입을 움직임 | 노래하듯 입을 움직이고 표정 변화가 큼 |

## 영상에 박혀 있는 요소

| 요소 | A | B |
|---|---|---|
| 상단 당찬동행 로고 | 있음 (전 구간) | 있음 (전 구간) |
| "Rhythm check" 문구 | 있음 (전 구간) | 있음 (전 구간) |
| "쉬운 손동작 안무" 자막 | 초반 약 3~4초 (1.5초 간격 프레임 기준 0·1.5·3.0초에 있고 4.5초에는 없음) | 없음 |

B는 머리 윗부분이 로고·문구 영역과 겹치는 순간이 있어서, **위쪽을 잘라내는 방식은 쓸 수 없습니다.**

## 주의점과 시험 항목

| # | 우려 | 영향 | 확인 방법 |
|---|---|---|---|
| V1 | 로고·문구·자막이 결과 영상에 번지거나 배경으로 따라 들어옴 | 결과물 품질 | T2 |
| V2 | 출연자의 표정(노래하는 입 모양)이 참여자 얼굴에 전이됨 | 어색할 수도, 재미 요소가 될 수도 있음 | T2 |
| V3 | 손가락 동작 오류 (A의 핵심) | 가장 큰 품질 위험 | T2 |
| V4 | 팔 교차·겹침 구간에서 팔이 뒤틀림 (B) | 품질 | T2 |
| V5 | 두 영상의 음량 차 약 6dB, A는 피크 0.0dB라 클리핑 가능성 | 음원 합성 시 정규화 필요 | T6 |
| V6 | B(37.8초)가 무료 10분 실행 제한에 걸림 | 구간 분할 필요 | T11 |
| V7 | B의 와이드 팬츠·긴 소매가 참여자 사진 의상과 달라 어색해짐 | 의상은 참여자 사진을 따르는지 확인 | T2, T13 |

## 입력 사진 권장 구도 (잠정)

두 영상 모두 허벅지 위까지 나오는 정면 구도라서, 참여자 사진도 **정면 상반신(허리 위~허벅지)**이 가장 잘 맞을 가능성이 높습니다. 전신 사진은 필요하지 않습니다. 실제로 그런지는 T13에서 확인합니다.
