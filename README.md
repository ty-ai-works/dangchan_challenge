## Mac에 내려받기

```bash
BASE="/Volumes/D/AI_Projects/Claude/01_Projects/20261012_당찬동행_춤따라하기"
mkdir -p "$BASE"
git clone --branch claude/charming-gates-j9pr4v \
  https://github.com/ty-ai-works/dangchan_challenge.git "$BASE/dangchan_challenge"
```

이후 최신 내용 받기:

```bash
git -C "$BASE/dangchan_challenge" pull --ff-only
```

저장소가 비공개라 인증이 막히면 GitHub 웹에서 해당 브랜치의 `Download ZIP`으로 받아도 됩니다.

## 저장소 규칙

1. **참여자 사진, 네이버폼 응답, 연락처는 절대 커밋하지 않습니다.** 시험용 사진은 본인 사진이나 AI로 만든 가상 인물만 씁니다.
2. 레퍼런스 영상 파일은 협회 허가 전까지 올리지 않습니다 (`.gitignore`로 막아 둠).
3. 결과 영상은 `results/` 아래에 올리고, 파일당 25MB 이하로 유지합니다.
4. 문서의 `⟦ ⟧` 표시는 측정이나 확인 후 채워야 하는 값입니다.
