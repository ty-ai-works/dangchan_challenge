# results — 시험·조사 결과

로컬 세션과 사용자가 시험·조사한 결과를 올리는 곳입니다. 무엇을 조사할지는 [docs/04_로컬_조사_요청서.md](../docs/04_로컬_조사_요청서.md)에 있습니다.

## 폴더 규칙

```
results/YYYYMMDD_주제/
├── 기록.md        # _templates/시험기록_템플릿.md 를 복사해서 작성
├── screens/       # 스크린샷
└── videos/        # 결과 영상 (파일당 25MB 이하)
```

예: `results/20261008_T1_공식템플릿실측/`

## 올리면 안 되는 것

- 참여자 사진, 네이버폼 응답, 연락처, 계정·토큰
- 제3자 사진 (시험용은 **본인 사진이나 AI로 만든 가상 인물**만)
- 레퍼런스 영상 원본 (협회 허가 전)
- 파일당 25MB를 넘는 영상 (줄이거나 링크로 대체)

## 기록 원칙

- 직접 측정한 값과 문서에서 읽은 값을 구분합니다. 문서에서 읽었다면 URL과 조회일을 적습니다.
- 실패한 시도도 기록합니다. 가이드의 "안 될 때" 항목의 근거가 됩니다.
- 스크린샷에 이메일·계정명이 보이면 가리고 올립니다.
